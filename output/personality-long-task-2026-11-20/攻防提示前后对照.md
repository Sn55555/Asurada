# 攻防提示前后对照

## 吉达真实日志，16 圈 Straight 03

同一辆前车，差距依次从 1.517 秒降至 1.417 秒，再到 1.333 秒。旧版在同一段的历史语音回执中没有攻防机会播报。候选版在比赛时钟 **1596.897 秒** 给出「先跟住」。差距变化保留在解释依据中。

用现有攻防语音的 macOS `say` 备援路径渲染，文件长 0.673 秒。以回放提交的开口位置加整句长度，得到关键词结束的保守估计 **1597.569 秒**。遥测记录首次有效制动在 **1602.203 秒**，比候选的赛段截止更早，留出约 **4.634 秒**。在同一回放中，「差距在收，先跟住」的较长初版会在 1598.503 秒被取消，动作词位于句尾，无法证明已说完。缩短后的候选完整播放。该赛段没有满足可执行进攻的策略条件，因此只给准备提示。

以上是历史遥测、真实资源文件长度与模拟播放调度的组合证据。真人耳麦播放与运动状态的同步测量仍待验证。

## 可重复构造的连续场景

| 条件 | 原策略或候选变化 |
|---|---|
| 差距连续收窄 | 原策略没有准备提示。候选先说「先跟住」。 |
| 同一前车的可执行窗口稳定形成 | 候选在短时间稳定确认后说「可以准备进攻」。保持同一机会 ID，手动开启进攻模式时仍只播一次。 |
| 后车逼近，动作建议已完整交付 | 候选撤回为「先守后车」。 |
| 窗口只出现一帧，或在排队时已经消失 | 旧行动句不播，也不会出现多余撤回。 |
| 紧急失稳、换前车或闪回 | 先退役旧机会。紧急失稳能压过低优先级机会，旧会话不会带来补播。 |
