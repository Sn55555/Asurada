# 共同策略如何改变下一场电台

本对照使用构造的遥测快照、正常共享语音入口和模拟播放器。两份档案均为 H1，完赛数和正向事件相同。唯一差异是一份档案有可回查的进站合作证据。

| 下一场问同一个问题 | 实际提交给语音调度的文字 |
|---|---|
| 没有共同策略记录 | 磨损 16%，正常，先继续。我会继续对照四轮磨损。要是连续读数显示轮胎风险升高，再重新评估进站。 |
| 有一次已验证的共同策略 | 磨损 16%，正常，先继续。上次换胎后磨损风险解除了。这次磨损升高再评估。 |
| 同一档案，当前读数升到 78% | 注意。轮胎磨损达到进站评估条件。当前磨损 78%。进站时机还要看交通。如果有效磨损读数回落，我会重算。 |

有共同经历时省掉四轮与连续读数的例行解释，同时保留当前结论和改判条件。磨损风险上来后，恢复给出完整理由。两份档案的紧急播报文本一致。完全沉默后自行换胎的样本记录换胎事实，没有计成采纳或共同策略。

单独的成长验证比较了 H1 阶段只有一次合作与两场各一次有效合作。当完赛、正向事件门槛均满足时，第二场合作和有效完赛使档位升到 H2。重复导入、不同驾驶员或不同闪回分支的样本不增加合作次数。撤销后重新导入不会复活该条合作，档案导出和重建一致。

燃油闭环使用独立的构造回放。一次实际提交的节油建议、明确回应、提前收油和相近绿旗圈的燃油数据按建议 ID 对齐。样本显示两圈耗油分别为 1.4 kg 和 1.2 kg，这是 0.2 kg 的观测差值。安全车样本标为结果未确认。
