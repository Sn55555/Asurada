# UI Direction

## Visual Theme

The app should feel like a mix of motorsport pit-wall tooling and premium athlete performance apps.

## Design Keywords

- precise
- technical
- fast
- focused
- premium

## Style Suggestions

- dark graphite or deep asphalt background
- high-contrast telemetry accents
- limited, semantic colors
- condensed numeric typography for timing
- large scrubber and playback controls

## Key Components

- session summary hero
- lap cards
- telemetry stat chips
- delta bar
- event marker pills
- interactive track map
- corner insight cards

## Motion

- smooth progress sweep along track
- subtle chart transitions
- snap points for sector and event markers

## Avoid

- too many charts on one screen
- gaming-style clutter
- oversized card spacing that hides dense data
