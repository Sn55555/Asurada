# Roadmap

## Phase 0: Definition

- confirm target users
- lock MVP scope
- define telemetry schema
- produce wireframes

## Phase 1: Foundation

- create Xcode project
- set up module structure
- define models and sample data
- build session list and session detail

## Phase 2: Replay MVP

- implement track map rendering
- build playback controller
- add telemetry timeline
- support one imported sample format

## Phase 3: Analysis MVP

- lap compare
- sector analysis
- event detection
- summary insight cards

## Phase 4: Polish

- visual tuning
- haptics and gestures
- export/share
- performance optimization

## First 2 Weeks Suggestion

1. Day 1-2: finalize product scope and sample telemetry format
2. Day 3-4: create SwiftUI app shell and navigation
3. Day 5-7: implement session models and sample import
4. Day 8-10: implement replay screen with fake playback
5. Day 11-14: implement lap compare and first insight cards
