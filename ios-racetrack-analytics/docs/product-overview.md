# Product Overview

## Product Positioning

An iOS app for racetrack data analysis and replay, aimed at users who want to review performance after practice, track days, testing, or competitive sessions.

## Target Users

- Amateur drivers: want an easy way to understand where time is lost
- Coaches: want clear playback and compare tools for driver feedback
- Teams/engineers: want quick session review on mobile
- Content creators: want telemetry-driven replay clips and highlights

## Core Value

- Turn raw telemetry into actionable feedback
- Make replay intuitive on mobile
- Help users answer three questions quickly:
  - Where did I gain or lose time?
  - What happened in this lap/session?
  - How should I improve next run?

## Key Scenarios

### 1. Post-session review

User imports a session from device, cloud, or external logger, then sees:

- lap list
- fastest lap
- sector breakdown
- incidents/events
- replay entry point

### 2. Lap-to-lap comparison

User compares fast lap vs reference lap and checks:

- delta time by segment
- throttle/brake overlap
- corner entry and exit speed
- racing line differences

### 3. Replay and storytelling

User watches track replay with synchronized:

- car position
- speed
- throttle
- brake
- steering
- g-force
- event markers

## MVP Feature Set

- Session import from JSON/CSV/GPX/custom logger format
- Session dashboard
- Lap list and lap detail
- Track map replay
- Telemetry timeline scrubber
- Lap compare mode
- Sector/corner analysis
- Event detection: lockup, oversteer, lift, pit in/out, invalid lap
- Basic export: screenshots/share cards

## Version 2 Ideas

- AI coaching summary
- cloud sync
- team workspace
- Apple Watch or action camera linkage
- setup notes and tire/weather correlation
- live timing companion mode
