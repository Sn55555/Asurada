# Information Architecture

## Main Navigation

Recommended bottom-tab structure:

1. Home
2. Sessions
3. Replay
4. Compare
5. Profile

## Screen Map

### Home

- recent sessions
- latest best lap
- improvement cards
- quick import

### Sessions

- session list
- filters by track, car, date, driver
- session detail

### Session Detail

- summary header
- lap ranking
- sector table
- event timeline
- weather/setup notes
- open replay
- compare laps

### Replay

- track map canvas
- moving car marker
- lap progress slider
- telemetry cards
- event timeline
- video panel if available

### Compare

- select two laps/sessions/drivers
- dual telemetry chart
- delta trace
- corner-by-corner insight cards

### Profile

- driver profile
- vehicles
- favorite tracks
- import sources
- preferences

## Important UX Principles

- One-thumb operation for core playback controls
- Fastest route from session detail to replay in one tap
- Charts should explain, not overwhelm
- Default to “best lap vs selected lap” comparison
- Use color consistently:
  - green for gain
  - red for loss
  - blue for neutral telemetry
