F1 25 数据采集与解析使用说明

一、这个文件夹里有什么

1. 01_开始采集_F1_25数据.bat
   给客户双击使用的采集入口。

2. 02_解析最新采集结果_生成CSV.bat
   给客户双击使用的解析入口。

3. f1_25_udp_capture.bat
   原始采集脚本。

4. f1_25_full_parse_to_csv.bat
   原始解析脚本。

5. f1_25_udp_capture.py
   采集的 Python 脚本源码。

6. f1_25_full_parse_to_csv.py
   全量解析的 Python 脚本源码。

7. f1_25_telemetry_structures.txt
   F1 25 官方 UDP 结构文件，已经一起打包，不需要额外联网下载。


二、怎么用

步骤 1：先采集

1. 打开 F1 25 游戏
2. 在游戏里开启 UDP Telemetry
3. UDP Port 建议设置为 20777
4. 双击“01_开始采集_F1_25数据.bat”
5. 输入采集分钟数，直接回车则默认采集 5 分钟
6. 开始跑游戏
7. 采集结束后，jsonl 文件会保存在 captures 文件夹


步骤 2：再解析

1. 双击“02_解析最新采集结果_生成CSV.bat”
2. 程序会自动找到 captures 目录里最新的 jsonl 文件
3. 解析后的 CSV 会输出到“解析结果”文件夹


三、输出文件在哪里

1. 原始采集文件：
   本文件夹下的 captures 目录

2. 解析后的 CSV：
   本文件夹下的 解析结果 目录


四、重要说明

1. 采集脚本可以直接在 Windows 上运行，不需要 Python。

2. 解析脚本需要 Windows 电脑已安装 Python 3。
   如果双击解析脚本时报错“Python 3 was not found”，说明这台电脑还没有安装 Python 3。

3. 如果只负责采集，不负责解析，那么只需要运行：
   01_开始采集_F1_25数据.bat

4. 如果需要提前结束采集，可以在采集窗口中按：
   Ctrl + C

六、常见问题

问题 1：为什么没有生成采集文件？
检查游戏里是否开启了 UDP Telemetry，端口是否是 20777。

问题 2：为什么解析失败？
优先检查 Windows 是否安装了 Python 3。

问题 3：CSV 很多，是不是正常？
正常。全量解析会按不同 packet 类型拆成多张 CSV。
