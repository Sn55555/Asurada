# Asurada 最终用户验收任务

状态：A01–A13 开发验证已完成，U01–U04 等待隼人最终验收；本表没有代填任何实机项目为通过。

本轮范围：核心、真实赛车数据、语音、Web、赛后复盘和训练。iOS 暂缓，ESP 适配与设备验收不做。开发进度以 [执行计划](ASURADA_ARCHITECTURE_IMPLEMENTATION_PLAN_CN.md) 最新进展为准。

## 开始条件与记录

开发侧 A01–A13 的逐项核对已完成。当前版本 182 个契约回归全部通过，干净构建/安装 11 项通过，无上限主抓包 31,726 个快照及四个重叠场次子集全部通过，源码/输入哈希一致。完整证据见 [交付索引](ASURADA_ARCHITECTURE_DELIVERY_CN.md)。这些是开发侧技术验证，真实供应商、麦克风识别、实际听音和驾驶价值仍按本表验收；当前未实现 AEC，不能把模拟服务、文件导出或耳机模式测试描述为 AEC 通过。

每次验收记录：日期、代码/资产版本、游戏版本、赛道和场次、音频输入输出设备、实际 ASR/TTS 后端、网络环境、日志或录屏位置。保存任务 ID、session UID/epoch 和问题发生时间；缺少对应证据的项保持待验收。录制回放、模拟后端通过与真实游戏/听音结果分别记录。

| U02-1 唤醒与问答 | 唤醒后提问、连续追问、静默等待 | 识别内容与实际说话一致，回复有声音、内容完整；无重复播放器 | 转写、轮次/任务 ID、听音记录 | 待验收 |
| U02-2 主动取消 | 在识别、解释、合成、播放阶段分别用停止入口取消 | 停止结果真实可听见，取消后的旧回复不再开始播放；失败明确显示未确认 | 各阶段时间、停止请求/确认与听音记录 | 待验收 |
| U02-3 抢占与过期 | 普通回复播放时触发高优先级事件，随后让遥测停止 | 抢占符合策略，无声音叠加；无新遥测时队列仍能推进/结束，过期项不播放 | 事件、队列回执、实际音频 | 待验收 |
| U02-4 网络与后端故障 | 请求中断网或让已配置服务不可用，再恢复 | 请求有界结束，资源不持续累积，错误不冒充成功；恢复后可再次问答 | 错误、健康信息、连续重试记录 | 待验收 |
| U02-5 播放期间输入 | 播放时发出停止指令，并测试键盘停止；记录回声情形 | 分别记录口头打断与键盘停止是否可用；不能用键盘通过替代口头/AEC 结果 | 麦克风和扬声器配置、转写、听音 | 待验收 |

当前 voice loop 的独立键盘停止为 `s + Enter`，退出为 `q + Enter`。口头打断需显式启用 `--spoken-interrupt`，使用耳机或隔离回声的输入，并说完整唤醒词加停止/取消。当前没有实现 AEC 回声消除算法；需分别记录耳机模式的口头打断、键盘停止和扬声器回声情形，不能由键盘测试通过推导口头打断或 AEC 通过。
